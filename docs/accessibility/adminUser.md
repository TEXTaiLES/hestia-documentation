# Admin User

Portal offers the ability to modify artifacts as an admin user.

## Admin Login

The Portal includes admin login functionality for authorized users. Admin credentials are the same as Directus user accounts, providing seamless authentication between the public Portal and the backend system.

## Editing Artifacts

Logging in as an admin enables users to edit annotations and manage content for artifacts in the Collections. 

### Workflow

1. Browse to the desired artifact in the Collections tab
2. Click the **"Annotate with THOTH"** button on the artifact page
3. The system automatically redirects you to the artifact scene in THOTH annotator tool
4. Make your edits and annotations
5. All modifications are automatically saved to the database

This streamlined workflow allows authorized users to quickly access and edit artifact data without manual navigation or separate login processes.
