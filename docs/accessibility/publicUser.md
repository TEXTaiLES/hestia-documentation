# Public User

Without login, every user can access the desired artifact from the Collections and explore its content freely.

## Public Access Features

Public users have full read-only access to the digital archive, enabling them to:

- **View high-quality 3D reconstructed models** interactively using the 3D model-viewer
- **Access detailed metadata and historical information** about each object retrieved from the database

## Browsing Experience

Public users can:

1. Browse all use cases (archaeological collections)
2. View previews of artifacts within each collection
3. Select any artifact for a detailed view
4. Interact with the 3D model using the viewer controls (rotate, zoom, pan)
5. Read comprehensive information about the artifact's history, origin, material and more.

No authentication is required for viewing and exploring the archive, making the cultural heritage artifacts accessible to researchers, students, and the general public worldwide.
