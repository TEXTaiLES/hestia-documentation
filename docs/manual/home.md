# Home

The Home page serves as the landing page for the Portal, providing visitors with an overview of the TEXTaiLES project and quick access to the main features of the digital archive.

## Overview

The Portal is organized into two main sections accessible from the navigation:

### Collections Tab

The Collections tab provides access to the complete digital archive of artifacts.

### Toolbox Tab

The Toolbox tab offers direct access to the TEXTaiLES suite of tools.

## Statistics

The Portal currently features:

- **Digitized Artifacts**: All objects from various archaeological collections
- **Use Cases**: 8 documented use cases demonstrating archeological collections
- **Available Tools**: 6 specialized tools for artifact analysis and annotation

*Note: Statistics are updated regularly as new artifacts and tools are added to the archive.*
