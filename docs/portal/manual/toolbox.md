# Toolbox

The Toolbox page provides direct access to every tool of the TEXTaiLES suite. Each tool is presented as a card showing its logo, name and a set of quick links.

## Available Tools

| Tool | Purpose |
|------|---------|
| **AmalthAI** | AI-powered detection, segmentation and classification for cultural heritage assets |
| **THOTH** | 3D annotation platform used to enrich artefacts with expert annotations |
| **ZEUSbot** | Robotic imaging system (UGV) for automated artefact acquisition |
| **NEPHELE** | 3D reconstruction pipeline based on SAMplify + SuGaR |
| **HESTIA** | The archive backend that powers this Portal — data management, storage, APIs |
| **INDRA** | Environmental Condition Monitoring for conservation environments |
| **DegraTwin** | Digital-twin modelling of degradation processes |
| **TexRevAIve** | AI-assisted textile revival and reconstruction |

## Links per Tool

Each card exposes up to three quick links, depending on the tool:

- **Documentation** — the dedicated documentation site (hosted on GitHub Pages).
- **GitHub** — the public source repository under the [TEXTaiLES organisation](https://github.com/TEXTaiLES).
- **Server** — a live deployment of the tool, when it is available online (currently AmalthAI, THOTH and NEPHELE).

## Where to Start

If you are exploring the ecosystem for the first time:

- To **view or annotate** artefacts, open **THOTH** (it is also launched automatically from an artefact detail page via the *Annotate with THOTH* button — see [Admin User](../accessibility/adminUser.md)).
- To **explore the imaging pipeline**, start with **ZEUSbot** (acquisition) and continue with **NEPHELE** (reconstruction).
- To **understand the archive itself**, follow the **HESTIA** documentation link.
